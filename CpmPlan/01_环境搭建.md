## 三、创建后端项目（ASP.NET Core Web API）

### 3.1 用 Visual Studio 创建

1. 打开 VS 2022 → 创建新项目
2. 选择 **ASP.NET Core Web API**
3. 项目名称：`CpmServer`
4. 框架选择 **.NET 8.0**
5. ✅ 勾选 **启用 OpenAPI 支持**（自动生成Swagger文档）
6. ❌ 不勾选 **使用控制器**（用 Minimal API 或稍后手动添加 Controller）

### 3.2 添加 NuGet 包

在 VS 中：工具 → NuGet 包管理器 → 管理解决方案的 NuGet 包，搜索并安装：

```
Microsoft.EntityFrameworkCore.SqlServer        (8.0.x)
Microsoft.EntityFrameworkCore.Tools            (8.0.x)
Microsoft.AspNetCore.Authentication.JwtBearer  (8.0.x)
Hangfire.AspNetCore                            (1.8.x)
Hangfire.SqlServer                             (1.8.x)
StackExchange.Redis                            (2.7.x)
BCrypt.Net-Next                                (4.0.x)
```

或在 **包管理器控制台**（工具 → NuGet 包管理器 → 程序包管理器控制台）执行：

```powershell
Install-Package Microsoft.EntityFrameworkCore.SqlServer
Install-Package Microsoft.EntityFrameworkCore.Tools
Install-Package Microsoft.AspNetCore.Authentication.JwtBearer
Install-Package Hangfire.AspNetCore
Install-Package Hangfire.SqlServer
Install-Package StackExchange.Redis
Install-Package BCrypt.Net-Next
```

### 3.3 项目目录结构

```
CpmServer/
├── CpmServer.csproj
├── appsettings.json
├── appsettings.Development.json
├── Program.cs
├── Controllers/              # API控制器
├── Models/                   # 实体类
├── Data/                     # DbContext
├── Services/                 # 业务逻辑
├── DTOs/                     # 数据传输对象
├── Common/                   # 公共类（Result、异常）
├── Hubs/                     # SignalR实时推送
└── Jobs/                     # Hangfire定时任务
```

### 3.4 配置文件 appsettings.json

```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=localhost;Database=CpmDb;Trusted_Connection=True;TrustServerCertificate=True;MultipleActiveResultSets=true"
  },
  "Jwt": {
    "Secret": "shibide-cpm-secret-key-2026-must-be-at-least-32-characters-long",
    "Issuer": "CpmServer",
    "Audience": "CpmWeb",
    "ExpirationHours": 24
  },
  "Redis": {
    "ConnectionString": "localhost:6379"
  },
  "Logging": {
    "LogLevel": {
      "Default": "Information",
      "Microsoft.AspNetCore": "Warning"
    }
  },
  "AllowedHosts": "*"
}
```

> **说明**：`Trusted_Connection=True` 表示用 Windows 身份验证连接 SQL Server，开发时最方便。生产环境可改成账号密码模式。

### 3.5 创建数据库（SSMS）

1. 打开 SQL Server Management Studio (SSMS)
2. 连接 `localhost`（Windows身份验证）
3. 右键"数据库" → 新建数据库 → 名称填 `CpmDb`
4. 确定

### 3.6 写一个测试接口

编辑 `Program.cs`，在 `var app = builder.Build();` 之后添加：

```csharp
app.MapGet("/api/test/hello", () => "Hello CPM");
```

按 **F5** 运行，浏览器访问：
```
https://localhost:7001/api/test/hello
```
或
```
http://localhost:5001/api/test/hello
```

应显示：`Hello CPM`

### 3.7 解决跨域（CORS）

在 `Program.cs` 中，builder 之后添加：

```csharp
builder.Services.AddCors(options =>
{
    options.AddPolicy("AllowVueApp", policy =>
    {
        policy.WithOrigins("http://localhost:5173")
              .AllowAnyHeader()
              .AllowAnyMethod();
    });
});
```

在 `app.MapControllers()` 之前添加：

```csharp
app.UseCors("AllowVueApp");
```

## 四、创建前端项目（Vue 3）

### 4.1 创建项目

打开 PowerShell，执行：

```bash
cd C:\你的项目目录
npm create vue@latest cpm-web
```

按提示选择：
- Add TypeScript? **Yes**
- Add JSX Support? No
- Add Vue Router? **Yes**
- Add Pinia? **Yes**
- Add Vitest? No
- Add Cypress? No
- Add ESLint? **Yes**
- Add Prettier? **Yes**

### 4.2 安装 Element Plus

```bash
cd cpm-web
npm install element-plus
npm install @element-plus/icons-vue
```

### 4.3 配置 Element Plus

编辑 `src/main.ts`：

```typescript
import { createApp } from 'vue'
import App from './App.vue'
import router from './router'
import { createPinia } from 'pinia'
import ElementPlus from 'element-plus'
import 'element-plus/dist/index.css'
import * as ElementPlusIconsVue from '@element-plus/icons-vue'

const app = createApp(App)

for (const [key, component] of Object.entries(ElementPlusIconsVue)) {
  app.component(key, component)
}

app.use(createPinia())
app.use(router)
app.use(ElementPlus)
app.mount('#app')
```

### 4.4 安装 Axios

```bash
npm install axios
```

### 4.5 配置 Axios

创建 `src/api/request.ts`：

```typescript
import axios from 'axios'

const request = axios.create({
  baseURL: 'http://localhost:5001/api',  // 对应.NET后端地址
  timeout: 10000
})

export default request
```

### 4.6 写测试页面

编辑 `src/views/HomeView.vue`：

```vue
<template>
  <div style="padding: 40px">
    <h1>CPM 系统</h1>
    <el-button type="primary" @click="sayHello">测试连接后端</el-button>
    <p v-if="msg">后端返回：{{ msg }}</p>
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue'
import request from '@/api/request'

const msg = ref('')

const sayHello = async () => {
  const res = await request.get('/test/hello')
  msg.value = res.data
}
</script>
```

### 4.7 启动前端

```bash
npm run dev
```

访问 http://localhost:5173 ，点击按钮，应显示"后端返回：Hello CPM"。
